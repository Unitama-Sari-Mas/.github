# Panduan Kontribusi

1. Buat branch dari `main`: `feat/nama-fitur`, `fix/nama-bug`, atau `chore/nama-tugas`.
2. Commit kecil dan jelas, contoh: `fix(api): perbaiki timeout koneksi Firebird`.
3. Buka Pull Request memakai template, minta minimal satu reviewer.
4. Jangan commit `.env`, kredensial, atau dump database.
5. Pastikan CI hijau sebelum merge.
